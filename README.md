- **Muốn hỏi**: vào mục [Hỏi đáp](https://github.com/phamtuanvn/ams-blog-community/discussions/categories/h%E1%BB%8Fi-%C4%91%C3%A1p).

- **Comment dưới bài blog**: [giscus](https://giscus.app) tự lưu vào mục Bình luận bài viết.
